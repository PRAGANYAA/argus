# ⚖️ ARGUS

### AI-Powered Rights Guidance & Undertrial Support

> **Turning legal rights into trackable, actionable workflows.**

## 🚨 Problem

India's prisons hold **hundreds of thousands of undertrial prisoners**. The core problem is not simply the absence of legal provisions — it is the gap between **legal eligibility, institutional action, and citizen awareness**.

Existing justice systems primarily manage cases, hearings, and risk. They do not continuously answer:

> **Who has crossed a legally relevant detention threshold, what action is required, and has that action actually happened?**

ARGUS addresses this **execution and accountability gap**.

---

# 💡 Solution

**ARGUS is an AI-assisted legal compliance and workflow platform that continuously monitors undertrial cases, computes configurable statutory thresholds, generates review dossiers, tracks recommendations to outcomes, and connects verified families to legal-aid information through SMS/IVR.**

### Core Pipeline

```text
Case Data
   ↓
Legal Rule Engine
   ↓
Eligibility / Threshold Detection
   ↓
Automated Case Flag
   ↓
Review Dossier
   ↓
Human Decision
   ↓
Recommendation Tracking
   ↓
Outcome Verification
   ↓
SMS / IVR Notification
```

---

# 🔥 Key Innovation

### ARGUS treats a legal entitlement as a **trackable compliance SLA**.

Unlike risk-prediction systems that estimate future criminal behaviour, ARGUS focuses on **deterministic legal thresholds and workflow execution**.

```text
Traditional AI
Risk → Prediction → Decision

ARGUS
Law → Threshold → Flag → Action → Outcome → Accountability
```

The system does **not** make judicial decisions.

It provides the intelligence and monitoring layer around them.

# 🤖 Multi-Agent Architecture

| Agent                          | Responsibility                           |
| ------------------------------ | ---------------------------------------- |
| 🔍 **Case Intelligence Agent** | Ingests and structures case data         |
| ⚖️ **Legal Eligibility Agent** | Applies configured statutory rules       |

| 📄 **Dossier Agent**           | Generates review-ready case summaries    |
| 📊 **Accountability Agent**    | Tracks recommendation → action → outcome |
| 📢 **Notification Agent**      | Triggers SMS/IVR notifications           |
| 🧑‍⚖️ **Legal-Aid Agent**      | Routes users to legal-aid services       |
| 🌐 **Language Agent**          | Multilingual text/voice interaction      |
| 🛡️ **Compliance Agent**       | Access, audit and policy validation      |
